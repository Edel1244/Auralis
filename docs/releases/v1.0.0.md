## AURALIS 1.0.0

İlk sürüm. / First release.

### 🇹🇷 Türkçe

**Masaüstü uygulaması (Windows)**
- `AURALIS-Setup-1.0.0.exe` dosyasını indirip kur. İlk açılışta AURALIS sunucunun adresini gir (ör. `https://muzik.ornek.com` ya da bu bilgisayarda çalışıyorsa `http://localhost:3000`).
- Hesabın, müziğin ve topluluk sunucuda durur; uygulama ona güvenli bir pencere açar.
- Uygulama yeni sürümleri kendisi denetler (menü → *Güncellemeleri denetle*). Yeni kurulum dosyası mevcut kurulumun üzerine kurulur, ayarların korunur.
- Kurulum dosyası henüz kod imzalı değil; Windows SmartScreen uyarı verirse *Ek bilgi → Yine de çalıştır* de.

**Bu sürümde yeni**
- Miks stüdyosu: **iki şarkıyı tek dosyada birleştirme** (ayarlanabilir geçiş süresi, tempo eşitleme, bas değişimi; WAV indirme ya da yeni parça olarak yayınlama) ve **otomatik geçiş** düğmesi.
- Ekolayzır: **bozulma koruması** (yükseltmeler artık sesi bozmuyor), canlı **frekans eğrisi**, eşleşen ön ayarın adını gösterme.
- Gizli/liste dışı öğelerde kilit rozetleri ve profilde **"Ziyaretçi gözüyle gör"**.
- E-posta: SMTP ayarlı değilse ekran artık "gönderildi" demiyor; geliştirme ortamında posta kutusu sayfası var.
- Hata düzeltmeleri: çalma listesi kapaklarında gizli parçaların görseli görünmüyor; ayarlar kaydedilirken ekolayzır geri sıçramıyor.

### 🇬🇧 English

**Desktop app (Windows)**
- Download and run `AURALIS-Setup-1.0.0.exe`. On first launch, enter your AURALIS server address (e.g. `https://music.example.com`, or `http://localhost:3000` if it runs on this computer).
- Your account, music and community live on the server; the app is a secure window onto it.
- The app checks for new versions itself (menu → *Check for updates*). A new installer upgrades the existing install and keeps your settings.
- The installer isn't code-signed yet; if Windows SmartScreen warns, choose *More info → Run anyway*.

**New in this release**
- Mixing Studio: **merge two songs into one file** (adjustable crossfade, tempo matching, bass swap; download as WAV or publish as a new track) and an **auto transition** button.
- Equalizer: **clipping protection** (boosts no longer distort), a live **frequency-response curve**, and the matching preset name is shown.
- Lock badges on private/unlisted items and **"View as visitors"** on profiles.
- Email: without SMTP the UI no longer claims a message was sent; development has a mailbox page.
- Fixes: playlist cover mosaics no longer show artwork of private tracks; the equalizer no longer snaps back while settings save.
